# Synthetic deal-doc dataset

All data here is **synthetic**. It contains no real customer, prospect, employer, or personal data, and no data from any real company. Names, companies, and email addresses are fictional.

- `scenarios/`: ground-truth deal specs (answer key A)
- `threads/{dev,test}/`: rendered email threads
- `labels/{dev,test}/`: labels mirrored from answer key A (blind hand-label B still needed)
- Split target: **12 dev / 28 test**
